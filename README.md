# Dünyanın En Yavaş Saat Çizicisi

![Yavaş](https://img.shields.io/badge/Hız-Yavaş-red)
![Ciddiyet](https://img.shields.io/badge/Ciddiyet-Maksimum-blue)

## Bu Nedir?

Bu, insanlığın en büyük sorununa çözüm getiren **devrim niteliğinde** bir yazılımdır:

**Saatleri yeterince yavaş çizememek.**

Artık o günler geride kaldı. Bu program, girdiğiniz saati ASCII art olarak çizer. Ama **yavaşça**. Çünkü acele iş şeytana.

## Nasıl Kullanılır?

```bash
python3 saat_cizici.py
```

Program size saati soracak, sonra her karakteri tek tek, acı verici bir yavaşlıkla ekrana basacak.

### Özellikler

- Gerçekten çalışır
- Aşırı yavaştır
- Hiçbir işe yaramaz
- Ama çok ciddidir
- Python 3 ile yazılmıştır (yavaş diller seviyoruz)

## Neden Var?

Çünkü bir gün birisi "saat çizmek çok hızlı oluyor" diye yakındı. Biz de bu projeyi yaptık. Şimdi kimse şikayet edemez.
